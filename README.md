# 弱网实验室 Android

安装包：`dist/WeakNet-1.0.1.apk`。Android 8.0（API 26）及以上，包含 arm64-v8a、armeabi-v7a、x86、x86_64。本地测试签名，不是应用商店发布版本。1.0.1 为健壮性修复版，沿用 1.0 签名，可覆盖升级；旧包仍保留。

## 使用

1. 将 APK 传到手机并安装，按系统提示允许该文件来源安装应用。
2. 打开“弱网实验室”，选择场景或输入上传、下载速度。
3. 点击“开始弱网测试”，允许系统 VPN 连接。通知权限用于显示运行状态和停止按钮。
4. 切换到需要测试的 App。修改参数后点击“应用新参数”。
5. 点击“停止并恢复网络”，或使用常驻通知中的停止操作。

例如：下载 512 Kbps、上传 128 Kbps、延迟 150 ms、抖动 30 ms、丢包 0%，适合先观察低带宽效果。1000 Kbps = 125 KB/s（十进制）。速率 0 表示不限速，断网请用独立开关。

## 已实现

- 上传、下载分别设置，全局聚合限速，不会因增加并发连接按倍数放宽上限。
- 每方向延迟、随机抖动、随机 IP 包丢弃、全断网模拟。
- TCP / UDP、IPv4 / IPv6 转发，实时 IP 字节速率、累计流量与丢包数。
- 慢速、拥堵、高延迟预设，参数保存，运行期间应用新参数。
- 本地 VPN、后台前台服务、通知停止按钮、撤销授权和失败时释放 VPN。

## 范围与限制

- 无需 root 或外部代理服务器。使用系统 VpnService，不能与其他 VPN 同时运行。影响进入该 VPN 的本机流量，工具自身除外；不包含热点客户端、其他用户/工作资料或系统绕过 VPN 的流量。
- 只降低可用速度，不能突破实际网络速度。上下行设定的是 IP 包吞吐上限，包含头部、确认包及重传；应用有效负载速度通常更低。
- 延迟施加到两个方向；150 ms 意味着额外往返延迟约 300 ms。实际还叠加网络时延及限速队列等待。抖动保持包顺序，可能造成相邻包聚集。
- 两方向分别按设定概率丢包。TCP 在本机用户态协议栈中终止，再由独立远端 TCP 连接转发；适合应用体验与重试测试，不等同于真实无线链路或远端 TCP 拥塞实验。
- 每方向最多排队 512 个包，队列满会额外丢包。修改参数会清空旧队列，已有 TCP 连接可能重传；断网后恢复也可能需要等待应用重连。
- 不支持 ICMP ping、原始 IP 协议和热点限速。不要用 ping 判断转发是否有效。
- DNS 配置为 223.5.5.5 / 1.1.1.1，私有企业域名可能无法解析；加密 DNS 的实际选择由 Android 和应用决定。
- 不解密 HTTPS、不保存访问内容。部分系统省电机制可能终止后台服务，可在手机设置中允许该应用后台运行。

## 构建

项目可在 Android Studio 中打开（AGP 8.13.0 / Gradle 8.13 / compileSdk 36，需要下载相应依赖和平台）。

本次 APK 用已安装 SDK 的命令行工具离线编译，无需下载 Gradle 依赖：

```powershell
.\test.ps1
.\build.ps1
# 或指定 SDK 根目录
.\build.ps1 -Sdk 'C:\path\to\Android\Sdk'
```

脚本依赖 PATH 中的 JDK 17+、SDK platform android-36.1 和 build-tools 36.1.0。本地签名密钥生成到 `.tools/weaknet-debug.jks`，未纳入 Git；保留密钥才能让后续 APK 覆盖安装。丢失密钥后需要卸载旧版本再安装。

已通过 Java 编译、DEX 编译、APK v2/v3 签名验证、包元数据检查，以及桌面 JVM 测试：限速单位与聚合调度、不限速、延迟顺序、参数校验、IPv4/IPv6 TCP 256 KiB 内容一致性与半关闭、IPv4/IPv6 UDP 回包、上游保护回调。

1.0.1 补充 `tests/RobustnessTest.java`：负值/溢出单调时钟、100 轮资源注册与关闭竞态、双向丢包、参数切换清队列、断网恢复、输出背压后的限速、700 包突发与队列容量、关闭时退出工作线程、并发错误只通知一次、畸形 UDP 的隔离、protect 失败拒绝连接、15 轮代理反复启停。详见 `ROBUSTNESS_REVIEW.md`。

**当前没有连接安卓设备，也没有可用 AVD。尚未进行手机安装、VPN 授权、JNI/socketpair 实机联通性、实际限速误差、长时间稳定性及各厂商兼容性测试。桌面测试不等于 Android 端到端测试。**

真机验收建议：先设速率/延迟/抖动/丢包全部为 0 验证网页、视频、DNS；再分别测试上下行限速；启用断网确认加载失败；停止确认连接恢复；最后测试屏幕关闭、Wi-Fi/移动数据切换、撤销 VPN 和连续启停。

## 实现和依赖

`VpnService TUN ↔ 有界 IP 包调度队列 ↔ Unix datagram socketpair ↔ hev tun2socks ↔ 本机 SOCKS5 ↔ 受保护的互联网套接字`。

转发内核使用 [hev-socks5-tunnel 2.18.0](https://github.com/heiher/hev-socks5-tunnel/releases/tag/2.18.0) 官方 AAR；原生 JNI 绑定保留上游包名。AAR SHA-256：`15EC8ED121663B562C99CAA5BB602D1009F24E5B09E733438B81988F12FEAAAB`。

上游及其依赖的许可证保存在 `third_party/`，并包含在 APK 的 `assets/licenses/`。Android VPN 行为依据 [官方 VPN 文档](https://developer.android.com/develop/connectivity/vpn)。
